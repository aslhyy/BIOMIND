# Frontend

Aplicacion Expo/React Native de Biomind.

```bash
npm install
npm start
```

Otros comandos disponibles:

```bash
npm run android
npm run ios
npm run web
npm run lint
node .\node_modules\typescript\bin\tsc --noEmit
```

Las variables de entorno locales deben guardarse en `frontend/.env`, usando
`.env.example` como referencia.
